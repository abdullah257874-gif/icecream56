frosty Dreams Ice Cream
A premium, colorful, responsive, and functional ice cream shop website built with React, Vite, Tailwind CSS, React Router, and localStorage cart persistence.

Live Demo
https://.github.io/frosty-dreams/

Features
Premium hero section and brand styling
Sticky responsive navigation bar
Product catalog with pricing, filters, and sorting states
Product detail page
Build-your-own custom box experience
Shopping cart with quantity updates and localStorage
Demo checkout and order confirmation
Offer banners and testimonial sections
Responsive layout for mobile and desktop
GitHub Pages deployment ready
Tech Stack
React
Vite
Tailwind CSS
React Router
Lucide React
LocalStorage
